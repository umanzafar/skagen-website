# Skagen

One-page site for Skagen, a documentary production and marketing agency based in Islamabad, Pakistan.

Single-page build (`index.html`, no build step) covering hero, a sliding client-logo marquee, services, process, results, team, and FAQ, styled around the brand's yellow/navy/black palette with Anton (headings) and Inter (body) typography.

See [`website-spec.md`](website-spec.md) for the full content and design spec this site was built from.
